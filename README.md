# 识文 Lite · 本地批量 OCR 与人工校对

中文桌面 OCR 工具：打开图片文件夹，批量识别文字，在原图旁核对和修改，再导出结果。支持代码截图、屏幕拍照、表格和按颜色去水印。

**Lite 是按需安装包，不是模型精简版。** 包内只包含应用源码、安装脚本和说明；Python、运行依赖、模型需要另行安装。使用同一模型时，Lite 不主动降低识别精度。

## 功能

- 递归处理 JPG、PNG、BMP、WebP、TIFF，支持多页 TIFF。
- 印刷文档、手写／拍照、表格／复杂排版、代码识别四种模式。
- 独立进程 OCR，支持队列进度、暂停、取消、失败重试和 CPU 重试。
- 原图区域与文字联动，人工编辑、低置信度提示、核对状态、自动保存和撤销。
- 代码校对支持等宽显示、缩进和行号，按语言导出源文件；不会执行识别出的代码。
- 按颜色去水印，提供处理图预览、背景替换、局部修补和批量重识别。
- TXT、Markdown、JSON 导出，表格另可导出 XLSX。

首版处理图片，不包含 PDF、云端 OCR、模型训练或持续监听新增文件。

## 平台状态

| 平台 | 状态 |
| --- | --- |
| Windows x64 + Python 3.12 | 已在 Windows / RTX 3050 6GB 上验证主要识别流程；支持 CPU 和可选 NVIDIA GPU |
| macOS Apple Silicon + 原生 ARM64 Python 3.12 | 提供 CPU 安装与启动脚本，**尚未完成 Mac 真机验收** |
| Intel Mac | 当前锁定的 Paddle 版本不提供对应安装包，暂不支持 OCR |

本项目没有已签名或公证的 macOS `.app`。不要把提供安装脚本理解为完成了全部跨平台测试。

Apple Silicon 独立应用的 DMG 构建方法见 [MAC_DMG.md](MAC_DMG.md)。应用自带 Python，使用者无需安装系统 Python；仍需在 Mac 上构建和完成真机验收。

## Windows 快速开始

1. 安装 **64 位 Python 3.12**，可从 [Python 官网](https://www.python.org/downloads/) 获取。
2. 将项目下载或克隆到可写目录；下载 ZIP 的用户请先解压，不要直接在压缩包内运行。
3. 双击 **安装轻量版.cmd**，首次联网安装界面、去水印和导出依赖。
4. 后续双击 **启动.cmd** 打开软件。
5. 点击顶部 **模型下载**，选择“基础文字 / 代码”和 CPU，勾选“同时安装所选功能的运行依赖”，点击“下载 / 安装 / 重试”。
6. 安装验证完成后，选择识别模式并打开图片文件夹。

如果系统没有 `py` 命令，可在项目目录的 PowerShell 中使用 Python 3.12 的完整路径执行：

```powershell
& "C:\你的Python目录\python.exe" tools/install_minimal.py
& ".\.venv\Scripts\python.exe" launch.pyw
```

安装脚本只在本目录创建 `.venv`，不要求将 OCR 库安装到系统 Python。

## macOS 安装（实验性）

安装原生 ARM64 Python 3.12。在解压或克隆后的项目目录运行：

```bash
bash 安装.command
bash 启动.command
```

如果找不到 `python3.12`，请先检查 Python 安装与 PATH。Rosetta 下的 x86 Python 不属于本版支持范围。模型窗口选择 CPU；基础、拍照和表格提供安装路径，但仍待 Mac 真机验证。完整说明见 [LITE_INSTALL.md](LITE_INSTALL.md)。

## 按需下载什么

| 选择的功能 | 模型 / 运行路径 |
| --- | --- |
| 基础文字 / 代码 | PP-OCRv6 medium；普通文档和代码转写共用 |
| 拍照方向校正 | 基础 OCR 加方向校正所需模型 |
| 表格 / 复杂排版 | PP-StructureV3 和解析依赖 |
| 文档 VL 增强 | PaddleOCR-VL 1.6，Windows 可选 |
| 代码 VL 增强 | 固定版本的代码微调模型，Windows 可选；revision 与权重校验见 models.lock.json |

首次只安装需要的功能即可。NVIDIA GPU 需在模型窗口另外选择，会切换本安装目录的 Paddle CPU/GPU 运行包，并额外下载 CUDA 相关依赖。安装时请先完成或取消 OCR 队列。

**轻量 ZIP 大小不等于最终占用。** 桌面运行依赖可能占数百 MB，OCR 与增强模型可能占数 GB；实际以所选功能、平台和下载器提示为准。不保证每个下载源都支持断点续传，失败后可点击重试复用有效缓存。

下载完成后保持“允许下载模型”未勾选，进行离线识别。缺少其他模式的模型时，请回到模型窗口安装，不要误认为基本模型包含全部能力。

## 去水印与校对

1. 点击“颜色去水印”，在样图上吸取水印颜色。
2. 优先使用“恢复自动背景色（推荐）”，检查实际处理图和匹配范围。
3. 保留需要的文字保护与半透明边缘处理，点击“仅此图”或“全部去水印并重识别”。

水印颜色是**要移除的颜色**，替换背景色应与原图背景一致。随意指定其他颜色可能只会给水印染色。水印和正文同色或覆盖正文时，无法保证区分和恢复；请核对代码符号、缩进和被覆盖位置。

原始图片不覆盖。去水印重识别后，未经人工修改、尚未核对的机器初稿可自动更新；已有人工修订的页面保留当前稿，新结果进入“版本 / 候选”，由用户采纳。可通过“查看去水印图”对比最近处理结果。

## 数据、网络与升级

- 识别和校对在本机运行，没有云端 OCR 回退。安装阶段联网获取 Python 依赖和公开模型，不上传待识别图片。
- `data/` 保存校对数据库、模型缓存、处理图、设置、日志和安装验证记录。JSON 和导出文件可能包含原文及本地路径。
- 换电脑或升级前请关闭软件，并备份整个 `data/`。**不要把自己的 data 目录提交到 GitHub 或附在公开 Issue 中。**
- 新目录安装不会自动迁移旧版数据，也不会删除旧版模型。旧完整版没有 pip 时，在模型窗口取消“同时安装运行依赖”，使用已有环境下载模型。
- 固定 UI 依赖见 `requirements-ui.lock.txt`，OCR 顶层版本见 `localocr/model_setup.py`。跨平台传递依赖由本机 pip 解析；本项目未声称提供完整 macOS 依赖锁。

## 常见问题

**软件能打开，但不能识别？** 先进入“模型下载”安装运行依赖和所选功能的模型。打开文件夹本身不会安装全部组件。

**下载失败？** 查看模型窗口日志，检查可用磁盘、网络和 Python 版本，再重试；无需重新安装整个应用。报告问题前请复制相关错误，并去掉路径、用户名等私人信息。

**GPU 显存不足？** 使用“CPU 重试”。VL 模型可能很慢，也不能保证在所有显卡或内存配置上成功运行。

**去水印后文字仍在？** 检查实际处理图、自动背景色、颜色容差和半透明边缘。如果页面已有人工修订，请查看新的 OCR 候选，旧稿不会被自动覆盖。

**结果与原文不同？** OCR 不是代码恢复或文字真实性保证。模糊、遮挡、手写、复杂表格和代码符号都需要人工核对。
